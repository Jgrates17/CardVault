🏀 The Card Vault

Basketball, Baseball & Football Trading Card Inventory & Portfolio Tracker

Version: 1.0  |  Date: April 29, 2026  |  URL: https://Jgrates17.github.io/CardVault/

1. Overview

  • Progressive Web App (PWA) — works on iPhone, Android, and any desktop browser
  • No app store, no developer account, no build tools required
  • Installable on iPhone via Safari → Share → "Add to Home Screen"
  • Offline support via service worker — works without internet after first load
  • All data stored locally in the browser (localStorage)
  • Hosted free on GitHub Pages

2. Features

Card Inventory Management

  • Add, edit, and delete trading cards
  • Capture front and back photos via camera or gallery
  • Automatic image compression (resized to 600×840, JPEG 70%) to stay within storage limits
  • OCR auto-scan — upload a front photo and the app attempts to auto-fill player name, team, brand, year, and card number using Tesseract.js (runs in-browser)

  • Panini Donruss, Panini Hoops, Panini Contenders, Panini National Treasures
  • Panini Flawless, Bowman

Portfolio Dashboard

  • Total collection value
  • Highest valued card (with player name)
  • Lowest valued card (with player name)
  • Average and median card values
  • Top 5 most valuable cards (clickable)
  • Value breakdown by Sport
  • Value breakdown by Brand
  • Value breakdown by Team
  • Value breakdown by Card Type
  • "Refresh All Values" button to recalculate

Search & Filter

  • Full-text search across player, brand, team, sport, and notes
  • Filter chips for Sport, Brand, Team, and Card Type
  • Sort options: Value ↓, Value ↑, Name A-Z, Newest, Oldest, Recently Added
  • Live result count and total value of filtered results

Import & Export

  • CSV Export — downloads card data (no images) as a .csv file
  • JSON Export — full backup including images and all fields
  • CSV Import — bulk add cards from a CSV file
  • JSON Import — restore from a full JSON backup

CSV Import Format

sport,playerName,team,brand,year,cardNumber,cardType,condition,isNumbered,serialNumber,notes

3. Pricing Engine

  • Currently uses a mock algorithm based on card attributes (brand, player, condition, type, year, numbered status)
  • Factors in known brand multipliers, star player multipliers, and condition grades
  • Designed to be swapped with a real API — edit js/services/pricing.js and replace the lookupCardValue() function body
  • Suggested real APIs: eBay Browse API, PSA Card Values, SportsCardsPro, PriceCharting

4. Technical Architecture

  • Stack: Pure HTML, CSS, vanilla JavaScript — zero dependencies, no build step
  • Storage: localStorage (~5MB browser limit)
  • Image compression: Canvas-based resize + JPEG encoding before storage
  • OCR: Tesseract.js v5 loaded from CDN on first scan
  • Offline: Service worker caches all app assets
  • Hosting: GitHub Pages (free, static file hosting)
  • PWA: Web app manifest + service worker for installability

5. How to Use

On iPhone

  • Open https://Jgrates17.github.io/CardVault/ in Safari
  • Tap the Share button → "Add to Home Screen"
  • Opens fullscreen like a native app, works offline

On Windows / Desktop

  • Open the URL in Chrome, Edge, or Firefox
  • Chrome/Edge will offer "Install app" in the address bar
  • Or just use it in the browser tab

Local Development

  • Open index.html directly in any browser — everything runs client-side
  • No Node.js, no npm, no build tools needed

6. Known Limitations

  • localStorage is capped at ~5MB — image compression helps but very large collections with photos may hit the limit
  • OCR accuracy varies by card design — works best on cards with clear, printed text
  • Pricing is mock/estimated — not connected to a live market data source yet
  • Data is per-browser — no cloud sync between devices
